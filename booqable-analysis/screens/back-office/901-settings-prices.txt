Security deposits
Charging Security Deposits
Watch video
Security deposits help protect your products. You can set a default deposit here and override it per customer or per order.

Learn more
Default security deposit
Set the default security deposit for new orders. This can be overridden per customer or per order.
No deposit
No security deposit is charged by default.
Percentage of order total
Charge a percentage of the total order value. For manual payments, you can also choose to authorize the deposit instead of charging it immediately.
Use product-specific security deposits
Calculate the deposit based on the security deposit set for each product. Product security deposits are set per product in Inventory.
Fixed amount
Charge a fixed security deposit for every order. For manual payments, you can also choose to authorize the deposit instead of charging it immediately.
